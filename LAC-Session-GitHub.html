Part I: Quick Fact Sheet

🌐 GitHub Pages

A free web-hosting service by GitHub that converts code files (like index.html) directly into live, interactive websites accessible via URL or QR code.

💡 Why Web Repositories?

  • Centralized: Access all resources in one place.
  • Open Source: Easy to adapt and customize.
  • Cross-Device: Runs on phones, tablets, or PCs.

Step 1: Get the Starter Code File

Click the green download button below to save the starter HTML code template to your device:

Download Starter Template File

Step 2: Create a Free GitHub Account
  1. Open github.com in a new tab.
  2. Click Sign up in the top-right corner.
  3. Enter your email address and set up your account credentials.
Step 3: Create Repository & Upload File
  1. On GitHub, click the + icon at top-right → Select New repository.
  2. Name your repository (e.g., my-subject-activity).
  3. Set visibility to Public. Click Create repository.
  4. Click uploading an existing file, drag and drop your downloaded index.html, and click Commit changes.
Step 4: Publish via GitHub Pages & Share
  1. Inside your repository, go to Settings → Click Pages on the left menu.
  2. Under Branch, select main (or master) and click Save.
  3. Wait 1–2 minutes, refresh, and copy your live URL:
    https://<your-username>.github.io/<repo-name>/
