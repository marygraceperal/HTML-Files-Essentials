Part I: Quick Fact Sheet

🌐 GitHub Pages

A free web-hosting service by GitHub that converts code files (like index.html) directly into live, interactive websites accessible via URL or QR code.

💡 Why Web Repositories?

  • Centralized: Access all resources in one place.
  • Open Source: Easy to adapt and customize.
  • Cross-Device: Runs on phones, tablets, or PCs.

Step-by-Step Guide: How to Create Your Own GitHub Repository
  1. Open github.com and sign up for a free account.
  2. Click the + icon at top-right → Select New repository.
  3. Name your repository, set visibility to Public, and click Create repository.
  4. Click uploading an existing file, drag and drop your index.html worksheet file, and click Commit changes.
  5. Go to Settings → Pages, select the main branch, and click Save to get your live URL.
