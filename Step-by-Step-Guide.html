Guide: HTML Learning Materials

Standard Operating Procedure for Generation, Verification, and GitHub Hosting

Task 1: Generating the HTML File

  1. Curriculum Guide Preparation
    Prepare the official Curriculum Guide (CG) corresponding to your assigned learning area.
  2. Select Language & Access Prompts
    Access the provided link, navigate to the Prompt Folder, and open the file matching your handled subject's medium of instruction.
  3. Customize Teacher Inputs
    Modify the designated Teacher Inputs enclosed within brackets (e.g., [...]) using the details from your Curriculum Guide.
    Note: Do not alter any other master prompt instructions to maintain structural integrity and layout styling.
  4. Generate HTML via AI
    Open your preferred Large Language Model platform (Gemini, ChatGPT, Claude, etc.), paste the finalized prompt, and initiate generation.
  5. Transfer Code to Notepad
    Copy the complete generated raw HTML code block and paste it directly into Notepad (or a preferred text editor).
  6. Save Document File
    In Notepad, navigate to File > Save As, select your local codes directory, and name the file using the .html extension (e.g., topic.html).
  7. Inspect and Refine
    Double-click the saved .html file to open it in a browser. If structural or content adjustments are needed, instruct the AI to revise the code and repeat steps 5 through 7.

Task 2: Pre-Upload Quality Verification

  1. Document Title Check
    Verify that the <title> tag reflects the correct lesson topic, as it displays on the web browser tab.
  2. Tab Navigation & Responsiveness
    Click through all 6 navigation tabs to verify script functionality and resize the browser window to confirm layout adaptability across different screen sizes.
  3. Print Layout Audit
    Execute a print preview (Ctrl + P) to confirm that print stylesheets correctly hide interactive elements like buttons and tab navigation bars.
  4. Content Completeness Audit
    Perform a final textual review to confirm no unpopulated bracketed fields, syntax codes, or truncated sentences remain in the document.

Task 3: Hosting via GitHub Pages

  1. Account Registration
    Register for an account at GitHub.com.
    Note: Select an appropriate username, as it will form part of your permanent public URL structure.
  2. Repository Creation
    From your dashboard, click New or the + icon to initiate a new repository.
  3. Repository Configuration
    Assign a repository name (e.g., learning-materials), set visibility to Public, and click Create repository.
  4. Upload File
    Click uploading an existing file, drag and drop your audited .html file into the browser, and click Commit changes.
  5. GitHub Pages Activation
    Navigate to repository Settings > Pages (left menu). Under Build and deployment, set the branch to main and click Save.
  6. Live Link Deployment
    Wait 1–2 minutes and refresh the page to obtain your published web link formatted as:

    https://[username].github.io/[repository-name]/[topic].html
